# Ordenación de Listas en Kotlin

**Autora:** Selene Muñoz Boza  
**Curso:** 2026/2027  
**Asignatura:** PMDM

## Descripción
Proyecto desarrollado en Kotlin que consiste en implementar y comparar cinco algoritmos de ordenación utilizando una lista de 40 vehículos y otra de 100 números aleatorios sin repetir.

## Algoritmos implementados
- **QuickSort:** ordena utilizando un pivote.
- **Pancake Sort:** ordena mediante inversiones de la lista.
- **MergeSort:** divide y combina listas ordenadas.
- **Bubble Sort:** compara e intercambia elementos consecutivos.
- **Insertion Sort:** inserta cada elemento en su posición correcta.

## Tecnologías
- Kotlin
- IntelliJ IDEA
- GitHub

## Ejecución
1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar el archivo `Main.kt`.
3. Consultar en la consola las listas ordenadas y los tiempos de ejecución.
